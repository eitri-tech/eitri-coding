# Platform specs behind the checks

What `check.mjs` verifies and why. Store requirements change; confirm against the current Apple Human Interface Guidelines / App Store Connect help and Android / Google Play Console documentation before a submission.

## iOS / iPadOS

| Item | Requirement | Check id |
| --- | --- | --- |
| Marketing icon size | exactly **1024×1024 px** PNG | `ios-size` |
| Alpha | **no transparency and no alpha channel** (even fully opaque pixels in an RGBA file are rejected) | `ios-alpha`, `ios-needs-background` |
| Shape | **square, full-bleed**; the system applies the rounded-rectangle (squircle) mask. Never pre-round | `ios-rounded` |
| Color space | sRGB, or Display P3 for wide gamut | `png-profile` |
| Margins | keep the glyph out of the outer ~5–10%; mask and glow crowd edges | `ios-tight`, `ios-small` |
| Appearances (iOS 18+) | default, **dark**, **tinted** variants; tinted converts the icon to a single hue, so luminance contrast carries the design | `contrast` |
| iOS 26 | layered icon authored in **Icon Composer** (`.icon`); the system renders **Liquid Glass** — translucency, specular highlights, blur, depth — in default/dark/clear/tinted | `baked-shadow`, see `modern-icons.md` |

`build.mjs` writes `ios/AppIcon-1024.png` as an RGB PNG (color type 2): it cannot carry an alpha channel.

## Android

| Item | Requirement | Check id |
| --- | --- | --- |
| Adaptive canvas | **108×108 dp** per layer (432 px at xxxhdpi, 324 xxhdpi, 216 xhdpi, 162 hdpi, 108 mdpi) | — |
| Visible area | the launcher mask shows at most the central **72×72 dp**; the outer 18 dp per side is for motion/parallax and is always cropped | `android-clipped` |
| Safe zone | keep essential art in the central **66 dp circle** (≈ 61% of the canvas diameter) so circle, squircle, rounded-square and teardrop masks all keep it | `android-safe-zone` |
| Layers | `background` (opaque, solid or simple) + `foreground` (transparent) + optional `monochrome` | `android-not-layered`, `android-layer-opaque` |
| Monochrome (themed icons, Android 13+) | single-color shape; only its **alpha** matters, the launcher tints it with the wallpaper-derived palette (Material You). Needs separable inner shapes | `android-monochrome` |
| Adaptive XML | `res/mipmap-anydpi-v26/ic_launcher.xml` (and `_round`) with `<background>`, `<foreground>`, `<monochrome>` | generated by `build.mjs` |
| Play Store icon | **512×512 px**, PNG (32-bit), **≤ 1024 KB**, sRGB, full-bleed square — Google applies the mask and shadow | `play-size`, `play-format`, `play-filesize` |
| Legacy (< API 26) | per-density square PNG launcher icons (48/72/96/144/192 px). Not generated: only needed when `minSdk < 26` | — |

## Pixel thresholds used (tunable in `lib/analyze.mjs`)

- Foreground mask = alpha ≥ 32 for transparent art; for opaque art, pixels more than 28 (RGB distance) from the dominant border color.
- `android-clipped` when > 0.2% of art pixels are outside the centered 72/108 square; `android-safe-zone` warning when > 1% are outside the 66/108 circle.
- `contrast`: median WCAG contrast ratio of artwork pixels against the background; **< 3:1** warns. Transparent art is measured on white and on black (and on `--bg` when given).
- `off-center`: bounding-box center more than 3% of the canvas away from the middle.
- `baked-shadow`: soft alpha (8–249) farther than ~0.6% of the canvas from any solid pixel, > 2% of the solid area.
- `ios-tight` < 5% margin; `ios-small` glyph < 30% of the canvas.
